# Documentation du Framework Vapor

</div>

Bienvenue sur la documentation du framework Vapor ! Vapor est un framework Swift pour le web, vous permettant de construire des backends, API pour webapps, et serveurs HTTP en Swift. Vapor est écrit en Swift, langage de programmation moderne, puissant et sécurisé, offrant de nombreux avantages par rapport aux autres langages serveur plus traditionnels.

## Pour démarrer

Vapor 5 est actuellement en développent actif, une documentation plus complète arrive prochainement.
